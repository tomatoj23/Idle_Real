# 014 · 装备构筑循环：铭纹池 + 纹阶 + 熔炼/重铸铭纹

**Blockers**: 004, 005
**来源**: docs/research/rebuild-research.md §1.2/§1.4（SexyMUD ADR-0005/0012）；ADR-011/015

## 范围
- content：铭纹池扩到 8~12 条（吸血/暴伤/连击/气血回复等）+ 2~3 条机制型特色铭纹（feature 用 condition+primitive 表达，引擎零新增）；三阶 tiers 数值表；器胚条目（floorRange/tierRange/preferredTags/胚纹）
- 引擎：`rollGear` 补全掉落管线步 ①⑦（掉不掉 / 掷纹阶）——口诀：**稀有度是因（词条数），纹阶是果（质量）**；标签加权抽铭纹（`权重 = 基础 × (1+匹配数×加成)`，新铭纹带 tags 自动被相关器胚青睐，扩池零改动）
- 引擎：**熔炼**（分解装备得器屑）+ **重铸铭纹**（消耗器屑重随单条铭纹数值，器胚 tierRange 数据锁死天花板）
- tag 倒排索引支撑跨集合批量查询；tags/flags 分工（ADR-015）
- UI：乾坤袋熔炼/重铸入口、铭纹展示（纹阶着色）
- 存档：实例加字段（纹阶/tags）走"未显式写入字段不落盘"约定（ADR-013），旧存档不迁移（ADR-008，零包袱）

## 验收
- [ ] 同器胚在不同层数段的掉落分布正确（floorRange 生效）
- [ ] tierRange=T3 器胚的铭纹阶位上限 T3；preferredTags 加权统计 1000 次 roll 可见偏移
- [ ] 熔炼 → 器屑入袋 → 重铸单条铭纹数值变化、其余词条不动、天花板不被突破
- [ ] 新增一条带 tags 的铭纹 = 纯 content JSON，引擎零改动
