# 004 · 垂直切片②：战斗 + 装备可玩

**Blockers**: 003, 013
**User stories**: US-3 US-4 US-14

## 范围
- 引擎：回合战斗解算（攻防/暴击/减伤公式）、伤害档判定（相对期望伤害）、事件流（attack/damage/loot/victory/defeat）、装备实例（稀有度 roll/词条/佩戴属性汇总/uid 体系）、掉落结算（材料+异宝）、自动嗑丹/自动再战、丹药 buff——**装备与 buff 属性全部产出修饰符走统一聚合管线（#013，ADR-011），不得分路直算**
- 文案：combat-text 词库抽取器（出招句+受击者主语后果句、「」招式名、致命一击门控）——引擎提供通用"过滤后随机抽取"
- **战斗摘要 + 同对手对照**（调研合入 2026-09-02）：victory 事件携带一行签名画像（由伤害构成产生，非纯数值统计）；存档加 `lastEncounter[enemyId]`（对照语："三日前苦战三十合，今日十一合击倒"）
- UI：战斗页（敌方卡+血条+叙事日志自动滚底+丹药快捷栏）、乾坤袋装备卡（稀有度着色+词条+佩戴/卖出）
- 回归集（旧版踩坑固化）：未注册招式兜底、日志滚动跟随、佩戴属性生效、伤害档可达重/濒死

- [ ] 假时钟 300 游戏秒打狼：胜利事件含灵石区间掉落、异宝按掉率出现、combat 经验事件
- [ ] 佩戴不同稀有度武器 → playerAtk snapshot 反映倍率+词条（经修饰符管线聚合）
- [ ] 装备加成与丹药 buff 同属性叠加 → 与单管线预期一致（无旁路）

- [ ] 战斗 500 场回归：无未捕获异常、日志容量受控、致命一击文案在残血+重击时出现
