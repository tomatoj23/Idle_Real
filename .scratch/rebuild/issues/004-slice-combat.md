# 004 · 垂直切片②：战斗 + 装备可玩

**Blockers**: 003
**User stories**: #3 #4 #14

## 范围
- 引擎：回合战斗解算（攻防/暴击/减伤公式）、伤害档判定（相对期望伤害）、事件流（attack/damage/loot/victory/defeat）、装备实例（稀有度 roll/词条/佩戴属性汇总/uid 体系）、掉落结算（材料+异宝）、自动嗑丹/自动再战、丹药 buff
- 文案：combat-text 词库抽取器（出招句+受击者主语后果句、「」招式名、致命一击门控）——引擎提供通用"过滤后随机抽取"
- UI：战斗页（敌方卡+血条+叙事日志自动滚底+丹药快捷栏）、乾坤袋装备卡（稀有度着色+词条+佩戴/卖出）
- 回归集（旧版踩坑固化）：未注册招式兜底、日志滚动跟随、佩戴属性生效、伤害档可达重/濒死

- [ ] 佩戴不同稀有度武器 → playerAtk snapshot 反映倍率+词条
- [ ] 战斗 500 场回归：无未捕获异常、日志容量受控、致命一击文案在残血+重击时出现
