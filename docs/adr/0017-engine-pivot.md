# ADR-017: 项目转向——从开发游戏到开发放置游戏引擎框架

日期：2026-09-05
状态：已接受（grilling 两轮十问裁决 + 五条附带推论，用户逐项确认）

## 背景

项目原定位是单机放置修仙游戏《问道长生》。经审计修复批 0-4（ADR-016），引擎/内容边界已经磨干净：engine 运行时零中文、字段中性，修仙性沉淀在 content 类型枚举、UI 外壳与五组机制键名（fist/pill/hp/crit/gp）。事实摸底（2026-09-05 code-explorer 报告）同时发现：editor 是 10 行空壳零依赖；app-desktop 存在 3 处公式复算违规（`ui.ts:571` 倍率投影 / `:563` STAT_LABEL / `:638` 购买力）与外壳文案硬编码。

用户裁决转向：不再单纯开发游戏，而是开发一个**专门生成这类游戏（放置类）的引擎**。

## 决策

### 根决策（第一轮）

1. **产品定义**：框架 + 生成器两层；**第一期只做框架层**（engine + content 协议 + 壳层义务），生成器层（脚手架 + AI 内容管线）后置。
2. **目标用户**：开发者与创作者分层；**第一阶段只服务会写代码的开发者**（npm 包 + 文档 + 模板形态）。
3. **游戏本体**：《问道长生》**继续并行开发**，作为框架的狗粮与真机验收载体。
4. **工程形态**：**维持 monorepo** 不拆仓；出现第二个真实消费者（第二款游戏）后再物理拆分。
5. **验收标准**：不改引擎代码，只写内容包 + 壳，产出一款**不同题材**的放置游戏并跑通核心循环。

### 泛化裁决（第二轮）

6. **content 包拆分**：**包内分目录不拆包**——`src/schema/`（通用协议：schema + types + validate）与 `src/packs/`（题材内容）分居；**default.json 的"引擎缺省包"地位取消**（`pack.ts` 的缺省 import 上移到 app-desktop，框架不含题材）。
7. **机制键改名**：现在改 `gp→gold`、`pill→consumable`、`fist→basic`（游戏未发布 + 旧存档不迁移 = 改名窗口唯一性）；包 scope `@wendao/*` 的中性化后置，随 content 拆分/发布决策走；存档键与根包名（游戏本体）保留。
8. **修仙协议泛化**：Element 七系**键域开放**（循 #21 VerbStyle 先例：patternProperties + 存在性校验，schema 不钉枚举）；CombatText 十键结构保留，槽位协议只审查"是否隐含中文语法假设"，不重构。
9. **UI 壳路线**：**自写壳路线**——第二款游戏重写 UI，app-desktop 仅作参考实现；engine 侧义务 = 清 3 处公式复算债 + 外壳文案归 content（ADR-016 延伸），保证"壳可以薄"。
10. **验收题材**：第二款游戏 = **西方魔幻**放置（英语域强制暴露拼音渗透点、法术学派替代五行、职业替代六艺）；泛化第一批完成后进 `/to-tickets` 作 tracer 票。

### 附带推论（可随裁决推翻）

- editor 空壳包冻结保留、零投入。
- ADR-006（LLM 接入）随生成器层后置，决议不废。
- 游戏侧 ADR（001 Electron / 002 Steam / 009 SDK 模拟等）全部维持，狗粮按原路线。
- API 稳定性承诺推迟：第二款游戏验收前允许破坏性变更，semver 到验收时点才谈。
- 存量票 #14 保留，实施时按框架定位重审；API 形态类票优先级升高。

## 理由

- 引擎机制核心（挂机循环/战斗解算/修饰符管线/装备掷点/存档/RNG/事件流）字段与结构已基本通用，框架化的边际成本低；修仙特化集中且可枚举（content 枚举层 + UI 层 + 五组键名）。
- 生成器路线工程量压在 editor 空壳与 AI 生成质量上，前置依赖框架 API 稳定，顺序不可反。
- 游戏继续开发本身就是对框架 API 的持续验证，且是最硬的验收手段；砍掉等于扔掉狗粮。
- 未发布状态是唯一的免费改名窗口，机制键名渗引擎/校验/schema/内容包四层，晚改成本滚雪球。
- 参数化模板壳会滑向配置地狱（UI 是放置游戏差异化最大的层）；引擎侧把"数据够用"做实，壳层自然薄。

## 后果

- 泛化第一批工作（后续 `/to-spec` → `/to-tickets` 排票）：①content 包内分目录 + 缺省题材包地位取消；②机制键改名三连；③Element 键域开放；④UI 公式复算清债 + 外壳文案归 content；⑤CombatText 槽位审查。
- CONTEXT.md 一句话定位改写为引擎 + 游戏双定位（本 ADR 同日执行）。
- 生成器层、editor、包 scope 中性化、semver、公开发布均显式后置，不属框架第一期。
